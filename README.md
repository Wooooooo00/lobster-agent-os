# Lobster Agent OS｜AI 業務飛行記錄儀

一個可直接運行的 MVP，用來把 OpenClaw / 龍蝦 Agent 的運行截圖、記憶讀取、業務研究、外聯生成與未來演化路線，包裝成可提交給 Xiaomi MiMo Token 申請的「項目證明頁」。

## 項目標題

**Lobster Agent OS｜AI 業務飛行記錄儀**

英文副標：

**Lobster Agent OS — AI Business Flight Recorder**

## 功能

- 五階段項目展示：System Online / Memory Connected / Business Research / Outreach Generation / Next Evolution
- 每個階段可上傳截圖證明
- 可修改項目標題與副標
- 可一鍵列印 / 匯出 PDF
- 可匯出單頁 HTML
- 本地運行，不上傳資料

## 安裝與運行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

打開瀏覽器：

```text
http://127.0.0.1:5173
```

## 建議放入的截圖

1. OpenClaw gateway running / agent model online
2. OpenClaw Web 控制台
3. memory_core 讀取成功
4. 91APP source verification table
5. 91APP outreach email / contact path result

## 用途

用作 MiMo Token 申請第 05 題「使用證明與影響力證明」的可視化補充材料。
